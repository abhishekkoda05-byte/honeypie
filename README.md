# &#x20;Honeypie – Clothing Exchange & Swap Marketplace

**Honeypie** is a clothing exchange and swap marketplace where users can list their pre-loved clothes, explore products uploaded by others, and exchange clothing through a simple swap system.

&#x20;**Live Website:** [https://honeypie-tawny.vercel.app/](https://honeypie-tawny.vercel.app/)

## &#x20;Features

- User registration and login with JWT authentication
- Upload and manage clothing products
- Cloudinary image storage
- Browse and search products by title and price
- View and edit user profiles
- Send and manage swap requests
- Accept or reject swap requests
- Mutual swap confirmation
- Swap history
- Real-time one-to-one chat using Socket.IO
- Swap value comparison

## &#x20;Project Objective

The main objective of Honeypie is to encourage sustainable fashion by allowing people to exchange clothes instead of always buying new ones. It promotes reuse, reduces clothing waste, and makes fashion more accessible.
